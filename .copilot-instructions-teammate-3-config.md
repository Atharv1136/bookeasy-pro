## Key Files Explained

### tsconfig.json
Controls TypeScript compilation. Key settings:
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "strict": true,
    "jsx": "react-jsx"
  }
}
```

### vite.config.ts
Configures the build tool:
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: { port: 3000 },
  build: { outDir: 'dist' }
})
```

### wrangler.jsonc
Configures Cloudflare Workers deployment:
```toml
[env.production]
name = "appointly-prod"
route = "example.com/*"
```

## Troubleshooting Common Issues

| Issue | Solution |
|-------|----------|
| Dependency conflicts | Run `bun install` to resolve |
| Build errors | Check TypeScript errors first |
| Type errors | Run `npm run type-check` |
| Linting errors | Run `npm run lint -- --fix` |
| Port already in use | Change port in vite.config.ts |
