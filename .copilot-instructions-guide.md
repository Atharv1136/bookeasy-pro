# 🤖 GitHub Copilot Custom Instructions Setup Guide

## Overview
Each teammate has a **personalized Copilot instruction file** that tells GitHub Copilot about their role, responsibilities, and the files they work with. This helps Copilot give better, more focused suggestions.

---

### **Teammate 1 (Frontend)**
📄 File: `.copilot-instructions-teammate-1-frontend.md`
- **Focus:** UI components, routing, styling
- **Copilot helps with:** React components, shadcn/ui, TanStack Router

### **Teammate 2 (Backend)**

### **Teammate 3 (Configuration)**

## 🎯 How to Use (For Each Teammate)

### **Step 1: Clone the Repository**
```bash
git clone https://github.com/Atharv1136/Appointly/
cd Appointly
```

### **Step 2: Open Your Instruction File**
Open the appropriate file in VS Code:
- Teammate 1: `.copilot-instructions-teammate-1-frontend.md`
- Teammate 2: `.copilot-instructions-teammate-2-backend.md`
- Teammate 3: `.copilot-instructions-teammate-3-config.md`

### **Step 3: Customize the Prompt**

Replace the placeholder:
```
[REPLACE_WITH_YOUR_NAME]
```
with your actual name.

**Example:**
```
# BEFORE
You are assisting **[REPLACE_WITH_YOUR_NAME]** who is...

# AFTER
You are assisting **John Doe** who is...
```

Also replace `[YOUR_NAME]` in git commands:
```
# BEFORE
git checkout -b feature/[YOUR_NAME]-frontend

# AFTER
git checkout -b feature/john-frontend
```

### **Step 4: Save Your Customized File**

The file should already be in your repo. Just make sure your changes are saved.

### **Step 5: Add to GitHub Copilot**

#### **Option A: VS Code Settings (Easiest)**
1. Open VS Code Settings: `Ctrl + ,` (Windows/Linux) or `Cmd + ,` (Mac)
2. Search: `copilot.advanced`
3. Look for **"Copilot: Custom Instructions"** setting
4. Copy entire contents of your customized `.copilot-instructions-*.md` file
5. Paste into the settings field
6. Save

#### **Option B: Use .copilot-instructions File (Automatic)**
If you rename your file to exactly `.copilot-instructions.md`, VS Code may automatically use it:
1. Rename your file: `.copilot-instructions-teammate-1-frontend.md` → `.copilot-instructions.md`
2. Restart VS Code
3. Copilot should automatically load it

#### **Option C: Copy Entire Content to Copilot Chat**
1. Open your customized file
2. Select all content (`Ctrl + A`)
3. Copy (`Ctrl + C`)
4. Go to GitHub Copilot Chat
5. Paste at the beginning: "Here are my instructions: [paste content]"
6. Then ask: "Remember these instructions for all future responses"

## 🆘 Troubleshooting

### Problem: Copilot isn't using my custom instructions
**Solution:**
1. Verify you've copied the content to Settings
2. Restart VS Code completely
3. Try Option C (copy into chat directly)

### Problem: Copilot still suggests modifying teammate's files
**Solution:**
1. Re-paste the full instruction text into Settings
2. Start chat with: "Remember my role is Frontend Developer"
3. Be specific in your questions: "In my frontend component, how do I..."

### Problem: I can't find "Copilot: Custom Instructions" in settings
**Solution:**
1. Update GitHub Copilot extension
2. Search "GitHub Copilot" in extensions
3. Click gear icon → Extension Settings
4. Look for "Advanced" → "Custom Instructions"

## 🎓 Pro Tips

✨ **Tip 1:** Be specific in your questions
```
❌ Bad:  "How do I make an input?"
✅ Good: "In my frontend component, create a login input using shadcn/ui button and input components"
```

✨ **Tip 2:** Reference the instruction file
```
In your question: "As mentioned in my custom instructions, I work on [my section]..."
```

✨ **Tip 3:** Keep it focused
```
Copilot works best when you ask about YOUR files only
Don't ask it to help teammates' sections
```

✨ **Tip 4:** Use context
```
"I have these existing components... How do I extend them for..."
```
